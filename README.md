# Observatorio Interactivo de incidencia delictiva — vista previa

Sitio estático del Observatorio Nacional Ciudadano con la incidencia delictiva
que publica el SESNSP: líneas de tendencia, mapa, tabla de variación, rankings
estatal y municipal, y descarga de datos.

**Ver el sitio:** https://leoxnv.github.io/observatorio-interactivo/

Este repo solo publica el sitio terminado. No se edita a mano: la rama
`gh-pages` la genera el pipeline (repo privado `leoxnv/delitosmexico-pipeline`,
`.github/workflows/sitio.yml`) y se reemplaza completa en cada publicación.
Cualquier cambio al sitio o a los datos se hace allá.

Fuente: Secretariado Ejecutivo del Sistema Nacional de Seguridad Pública.
